# Influence Warfare – Neural State Reorganisation

This repository contains supplementary figures and processed CSV outputs supporting the exploratory EEG analyses presented in the accompanying paper, *Influence Warfare Beyond Narratives: Cognitive State Manipulation in the Attention Age*.

The purpose of this repository is to make the paper’s biological examples easier to inspect without turning the paper itself into a technical neuroscience report. The figures are intended to illustrate that cognitive state can be examined as a measurable, dynamic pattern of system organisation rather than treated only as a metaphor for mood, opinion, or belief.

Rather than relying on any single EEG metric, the repository presents multiple analytical perspectives that together characterise how cortical organisation changes under different operating conditions. Each analysis examines a distinct property of the underlying system while complementing the others.

These materials are best read as a set of complementary views on neural state organisation:

- **Spectral State Dynamics** examines functional coordination and synchronisation across EEG channels.
- **Entropy and Complexity Metrics** examines information distribution and temporal sequence structure.
- **Frequency × Channel Reorganisation** examines where spectral power changes are distributed across channels and bands.
- **Temporal Stability and Persistence Analysis** examines how long particular state patterns are maintained.
- **Reorganisation Velocity (State-Space Flux)** examines how quickly neural state moves through spectral state space.
- **Differential Entropy and Regionalised Flux Difference Analysis** examines how information dynamics and reorganisation velocity change relative to baseline.

The analytical emphasis is not any single metric. The repository uses multiple measures because cognitive state is a systems-level construct: coordination, distribution, persistence, spatial patterning, and state-transition velocity each describe different aspects of the same broader operating condition.

These outputs should not be interpreted as clinical evidence, diagnostic evidence, or proof that a specific modulation method produced a specific cognitive outcome. They are exploratory supplementary analyses.

The central claim supported by the figures is narrower and more useful for the paper: cognitive state is measurable, dynamic, and associated with changes in how information-processing systems are organised. This matters for influence warfare because external information is not processed by a neutral receiver. It is processed through an existing biological operating condition that shapes attention, salience, uncertainty, identity, emotional weighting, and behavioural readiness.

EEG signals were recorded with the Emotiv Flex 2.0, a 32-channel wireless EEG system configured according to the international 10–20 electrode layout. The sampling rate for raw EEG data was 256 Hz, and band-power/FFT-derived metrics were calculated at an 8 Hz cadence.

Raw EEG recordings and analysis scripts are withheld from this public repository for privacy, confidentiality, and intellectual-property reasons. The recordings are sensitive personal neurophysiological data, and the analysis scripts form part of proprietary, confidential analytical workflows. Processed figures and summary CSV outputs are provided instead, allowing transparent inspection of the reported analytical results without disclosing protected source material.
